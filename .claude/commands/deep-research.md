# /deep-research

Perform comprehensive deep research on a specific topic using Perplexity's sonar-deep-research model.

## Usage

```
/deep-research [topic]
/deep-research                     # Interactive topic picker
/deep-research "AI Agents"         # Direct topic
/deep-research --topics primary    # Show only primary topics
```

## Parameters

- `topic` (optional): Topic to research. If omitted, shows interactive picker from topics.yaml.
- `--topics [filter]`: Filter picker — `primary`, `secondary`, `all` (default)
- `--effort [level]`: Research depth — `low`, `medium` (default), `high`

## Prerequisites

- Perplexity configured (`./scripts/enable-perplexity.sh`)
- `config/research.yaml` exists with deep research budget
- Deep research budget not exceeded

## Execution Steps

### Step 1: Load Configuration

Read: `config/topics.yaml`, `config/research.yaml` (deep research settings), `system/cache/perplexity/usage.yaml`.

### Step 2: Determine Topic

**If topic provided**: Use directly, skip to Step 3.

**If no topic (Interactive Picker)**:
1. Load topics from topics.yaml, filter by `--topics` flag
2. Present via AskUserQuestion with numbered options + custom topic option
3. Parse selection (number → topic name, custom text → use as topic, cancel → exit)

### Step 3: Check Budget

Follow **Budget Check (Deep Research)** in `perplexity-procedures.md`.

### Step 4: Execute Deep Research

1. Load query template from research.yaml → `query_templates.deep_research`
2. Replace `{topic}` placeholder
3. Determine effort from `--effort` flag or research.yaml default
4. Call `mcp__perplexity__perplexity_research` with `strip_thinking: true`
5. Parse response into: Executive Summary, Market Landscape, Key Players & Developments, Emerging Patterns & Signals, Competitive Dynamics, Strategic Implications, Recommended Actions, Sources

### Step 5: Update Usage

Follow **Usage Update (Deep Research)** in `perplexity-procedures.md`.

### Step 7: Write Output File

- Generate slug: topic → lowercase, spaces to hyphens
- Write to: `2-research/market-briefs/{YYYY-MM-DD}-{HHMM}-deep-research-{slug}.md`
- Display completion: topic, cost, budget remaining, output path

### Step 8: Sync to Notion

Follow **Sync-Agent: Write** in `agent-execution-guide.md`:
- Database: `market_intelligence`
- Properties: Title: "Deep Research: {topic}", Date, Priority: "High", Topics, Source: output path, Summary: executive_summary, Type: "Deep Research", Status: "New"

### Step 9: Update STATUS.md

Set Last Command, Last Output, add Activity Log entry.

## Error Handling

- **API error**: Log, show user-friendly message, suggest `--effort low`
- **Budget exceeded**: Show status, suggest waiting or adjusting budget in research.yaml
- **Invalid topic**: Fall back to interactive picker
