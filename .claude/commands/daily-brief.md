# /daily-brief

Generate a personalized daily briefing combining market intelligence with priorities.

## Usage

```
/daily-brief [options]
```

## Parameters (Optional)

- `--length`: Brief length (default: "standard") — `quick` (5 min), `standard` (10 min), `comprehensive` (deep dive)
- `--include-todos`: Include pending tasks from Notion (default: false)
- `--no-real-time`: Skip Perplexity queries, use only configured sources
- `--force-fresh`: Ignore Perplexity cache and fetch fresh data

## Orchestration Flow

**IMPORTANT**: Perplexity calls run at orchestrator level (sub-agents don't have MCP access).

```
Orchestrator                     →     intelligence-agent (quick mode)
─────────────────────────────────────────────────────────────────────
1. Parse parameters
2. Load configs (topics, sources, research, goals, notion-mapping)
3. Filter high-priority sources only (max 5)
4-6. Perplexity: cache check → MCP call (max 2 queries) → write cache + usage
7. Construct quick-mode input
                                 →    8-11. Quick scan, synthesize, return JSON
12. Receive + validate JSON      ←
13. Query Notion todos (if --include-todos)
14. Generate content opportunity
15. Format brief markdown
16. Write files + agent log
17. Sync to Notion (sync-agent)
```

## Execution Steps

### Step 1: Load Configuration

Read: `config/topics.yaml`, `config/sources.yaml` (filter high-priority, max 5), `config/notion-mapping.yaml`, `config/goals.yaml`, `config/research.yaml` (if exists), `system/cache/perplexity/usage.yaml` (for budget display).

### Step 1.5: Breaking News Discovery (Perplexity)

Skip if: `--no-real-time`, research.yaml missing/disabled, or budget exceeded.

Follow **Cache Check** in `perplexity-procedures.md` with `cache_key = {YYYY-MM-DD}-quick-daily-brief`.

Call `mcp__perplexity__perplexity_search` with breaking news template from research.yaml (max 1-2 queries).

Follow **Cache Write** and **Usage Update (Regular)** in `perplexity-procedures.md`.

Prepare `perplexity_results` using **Results Format** from `perplexity-procedures.md`.

### Step 2: Invoke Intelligence Agent (Quick Mode)

Follow **Agent Invocation** in `agent-execution-guide.md` with:
- Agent: `intelligence-agent`, Model: `sonnet`
- Input: `mode: "quick"`, `depth: "quick"`, `timeframe: "24h"`, primary topics only, high-priority sources max 5
- Include prompt: "CRITICAL: Use Firecrawl MCP for all web scraping. Perplexity results are pre-fetched - do NOT call Perplexity MCP."
- Target: 5-7 insights max

Validate output per `agent-execution-guide.md` → **JSON Validation** against `schemas.json → agents.intelligence-agent`.

Required fields: `real_time_intelligence.status`, `insights` (array, min 1), `content_opportunities`, `sources_scanned`, `scan_metadata.degraded_mode`.

### Step 3: Query Notion Tasks (if --include-todos)

Follow **Sync-Agent: Query** in `agent-execution-guide.md`:
- Database: `tasks`, Filters: `{ "Status": "In Progress" }`

### Step 4: Generate Content Opportunity

From intelligence-agent output, select top `content_opportunity` by urgency and pillar fit, enrich with "why now" context.

### Step 5: Format Brief Markdown

```markdown
# Daily Brief: {date}

## Report Metadata
| Field | Value |
|-------|-------|
| **Generated** | {timestamp} |
| **Report Type** | daily-brief |
| **Status** | {degraded_mode ? "degraded" : "success"} |
| **Real-Time** | {real_time_intelligence.status} |

---

{Status banners per perplexity-procedures.md}

## Good Morning, Enrique

{If breaking_news not empty:}
### 🔴 What's Breaking (Last 48h)
{Top 3 breaking news: title, summary, source links}

---

### Must-Know Today
{Top 5 insights (High/Medium priority): title, summary, source link}

### Metrics Snapshot
{From goals.yaml: LinkedIn followers, newsletter subs, content published, Perplexity budget}

{If --include-todos and tasks found:}
### Priority Tasks
{Task checklist}

### Content Opportunity of the Day
**Topic**: {topic} | **Why now**: {reason} | **Angle**: {angle} | **Pillar**: {pillar}

### Recommended Reading
{Top 3 insights with links and angles}

### Focus Suggestion
{1-2 sentence recommendation based on today's intelligence}

---

## Sources
| Source | URL | Type |
{all unique sources}

---
*Generated by PersonalOS | intelligence-agent (quick mode) | {date}*
```

### Step 6: Write Output File

- Markdown: `2-research/daily-briefs/{YYYY-MM-DD}-{HHMM}-brief.md`
- Agent log: `system/logs/{YYYY-MM-DD}-{HHMM}-daily-brief-agent.json`

### Step 7: Sync to Notion

Follow **Sync-Agent: Write** in `agent-execution-guide.md`:
- Database: `daily_briefs`
- Properties: Title: "Daily Brief - {date}", Date, Status: "Generated", content: full markdown

## Length Variations

| Length | Insights | Details |
|--------|----------|---------|
| quick | Top 3 | No metrics, no tasks, minimal |
| standard | Top 5-7 | Full format |
| comprehensive | All | Include medium-priority insights |

## Error Handling

### Intelligence Agent Fails Completely
Generate minimal brief with goals.yaml metrics and focus suggestion fallback.

### Other Failures
Follow **Partial Results Handling** in `agent-execution-guide.md`.
